# 厨神与吃货 · 本地纯净版（微信小程序）

纯本地离线运行的家庭电子菜单、点餐协作与厨房管理微信小程序。

## 核心特点（对比原版精简与本地化）
- **零后端 / 零登录 / 零支付广告**：所有数据保存在本地 `wx.getStorageSync` / `wx.setStorageSync`，彻底移除了 VIP 会员充值、积分任务体系、发现/社区信息流、远程后台以及第三方数据上报。
- **开箱即用**：原生微信小程序语法（WXML + WXSS + JS），无需安装 npm 依赖或构建工具，直接用微信开发者工具打开当前目录即可预览调试。

## 四大核心板块（12 个页面）
1. **厨房（`pages/index/index`）**：
   - 多厨房切换与主题配色 / 店招公告自定义（`pages/categoryManagement/index`）
   - 左侧分类导航 + 右侧点单 + 口味规格选择弹窗 + 悬浮菜篮子
   - 菜谱详情支持冰箱库存实时核对、步骤内分钟数一键开启计时（`pages/cookbookDetails/index`）
   - 手动添加菜谱 & 粘贴小红书/下厨房菜谱文本智能识别导入（`pages/addCookbook/index`）
   - 「今天吃什么」随机点菜抽签（`pages/randomDish/index`）
2. **订单（`pages/cook/index`）**：
   - 提交点单（选日期、早/午/下午茶/晚餐次、吃货称呼、忌口备注，`pages/submitOrder/index`）
   - 待做订单流转、做菜完成拍照打卡与作品墙、可选自动扣减冰箱食材库存
   - 「去买菜」智能清单：自动汇总待做订单与近 2 天饮食计划食材、对比冰箱库存标记缺口、勾选已买一键入库冰箱（`pages/vegetableBasket/index`）
   - 7 天三餐饮食计划日历，支持一键转为待做订单（`pages/mealPlan/index`）
3. **冰箱（`pages/storageSpace/index`）**：
   - 冷藏保鲜、冷冻囤货、常温干货、调料酱汁四大分区
   - 保质期自动计算（新鲜 / 3天内临期预警 / 已过期）与快捷数量加减
4. **我的与工具箱（`pages/my/index`）**：
   - 厨神 / 吃货身份切换与家庭统计看板（累计下厨次数、拿手菜 Top 3）
   - 多路并发做菜计时器（`pages/timerManagement/index`）
   - 家庭共享与本地备份：支持一键导出当前厨房菜单口令或全量 JSON 备份至剪贴板，发给家人即可导入同步菜单
